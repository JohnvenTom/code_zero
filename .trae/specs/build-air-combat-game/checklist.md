# Checklist

## 飞行与操控

* [ ] 玩家可从跑道滑跑起飞，360° 自由飞行，完成高G转弯、滚筒、俯冲拉升，无万向节死锁或姿态失控

* [ ] 速度低于失速阈值时机头下沉掉高度，恢复速度后可重新操控

* [ ] 战机接触地面/海面时判定坠毁爆炸，触发失败流程

* [ ] G值随机动实时变化且 HUD 显示与模拟值一致

## 战斗系统

* [ ] 机炮可开火，命中敌目标扣血并给出命中反馈（曳光/命中提示），弹药递减

* [ ] 目标进入锁定锥保持锁定时间后完成锁定，出锥/超距后锁定丢失

* [ ] 导弹发射后追踪目标，近距离近炸引爆命中，追踪失败时脱靶自毁

* [ ] 玩家释放干扰弹可按概率诱偏来袭导弹（规避成功）

* [ ] 敌机被锁定/导弹来袭时执行规避机动并释放干扰弹，存在规避成功的可能

* [ ] 敌机会主动追击玩家并进入包线后开火（机炮/导弹），构成实际威胁

## 任务与结算

* [ ] 存在 1 个完整战役任务，流程为：简报 → 入场 → 目标推进 → 胜利/失败结算

* [ ] 胜利条件（必需目标全部完成）正确触发胜利结算

* [ ] 三种失败条件（玩家坠毁/任务超时/保护目标全部损毁）均正确触发失败结算

* [ ] 结算界面展示得分、评价等级、击坠数、用时，支持重开任务

## 战机与武器

* [ ] 提供 3 架可选战机，速度/机动性/装甲差异可通过实际操控感知（影响战斗手感）

* [ ] 每架战机配备不同特殊武器且实际生效，弹药独立计数

* [ ] 机库/选择界面可正常选机并携带配置进入任务

## 僚机系统

* [ ] 2-3 架僚机默认编队跟随玩家，随玩家机动不掉队

* [ ] 进攻/掩护/集合指令可循环切换并生效，HUD 显示当前指令

## HUD 与界面

* [ ] HUD 完整显示：雷达（敌我识别）、高度、速度、G值、导弹数量、损伤值、锁定提示、任务倒计时

* [ ] 锁定完成与被敌方锁定告警均有明确 HUD 提示

* [ ] 窗口 resize 后画布与 HUD 自适应，无错位重叠

## 视觉与性能

* [ ] 天空、云层、昼夜光照氛围存在且不遮挡核心空战视区

* [ ] 空爆/地面爆炸特效、导弹尾焰烟迹正常呈现

* [ ] 任务开场有简报文字叙事

* [ ] 常规战斗场景帧率稳定可玩（目标 60fps），无明显卡顿

## 代码质量

* [ ] 代码遵循 simulation（规则/AI/任务状态）/ render（Three.js 适配）/ ui（DOM HUD）目录边界，游戏状态不驻留 Three.js 对象

* [ ] 所有函数附函数级注释（功能、参数、返回值、异常、注意事项）

* [ ] 战机/武器/任务均由配置表数据驱动
