# Checklist

## 飞行与操控

* [x] 玩家可从跑道滑跑起飞，360° 自由飞行，完成高G转弯、滚筒、俯冲拉升，无万向节死锁或姿态失控
  * 验证：实测滑跑→拉杆离地→爬升；滚转 360° 后倒飞负 G（-0.7）正常回正；满 G 筋斗（G 10.8 钳制于红隼 11G 上限）；负 G 俯冲（-3.1 渐近 4G 下限）；全程四元数局部旋转无万向节死锁

* [x] 速度低于失速阈值时机头下沉掉高度，恢复速度后可重新操控
  * 验证：代码审查——stallSeverity 随速度亏损加深、stallPitchDropRate 机头下压、stallSinkRate 附加下沉、controlAuthorityFloor 操纵权限地板（失速后 authority=速度/失速速度，恢复速度即恢复满操纵）；HUD 失速告警样式联动完整

* [x] 战机接触地面/海面时判定坠毁爆炸，触发失败流程
  * 验证：坠地判定（position.y < gearHeight - crashMargin → alive=false + crashed）→ player-crash 事件 → 大型爆炸特效 + 坠毁 HUD + mission.fail('player-destroyed') → 失败结算；玩家死亡统一播报路径（两局实测被击落走同一 fail 管线）

* [x] G值随机动实时变化且 HUD 显示与模拟值一致
  * 验证：实测 G 1.0（平飞）→ 11.0（满拉杆，精确钳制于红隼 gLimitPositive=11）→ -0.7（倒飞）→ -3.1（推杆渐近 gLimitNegative=4）→ 10.8（稳态盘旋）；G 限动器按速度动态限制俯仰角速率

## 战斗系统

* [x] 机炮可开火，命中敌目标扣血并给出命中反馈（曳光/命中提示），弹药递减
  * 验证：实测玩家机炮弹药递减（550→546）；曳光弹实体沿速度取向渲染；gun-hit 事件 → HUD 命中标记动画 + 命中火花特效；僚机经同一伤害管线实际击坠敌机（两局累计 4+ 架）

* [x] 目标进入锁定锥保持锁定时间后完成锁定，出锥/超距后锁定丢失
  * 验证：实测锁定锥检测与进度显示（LOCK 5% 累计）、锁定完成（LOCKED 文案+红色实线框）、锁定框屏幕空间定位（渲染层投影）；LockTracker 锥内累计/出锥丢失/切换清零/超距丢弃逻辑完整

* [x] 导弹发射后追踪目标，近距离近炸引爆命中，追踪失败时脱靶自毁
  * 验证：受限转向制导（turnRate×dt 步进转向）、近炸引信（proximityFuse 距离判定→伤害结算+空爆特效）、寿命归零/触地 missile-miss 自毁；敌机导弹实际命中玩家（第三局 HP 80→0）；玩家无锁定时 F 键正确拒绝发射（实测 MSL 不变）

* [x] 玩家释放干扰弹可按概率诱偏来袭导弹（规避成功）
  * 验证：实测玩家释放干扰弹（FLR 6→4 递减）；诱偏机制完整——单次掷骰（decoyChecked 防概率累积）、deceptionRange 320m 判定、65% 概率改追干扰弹、flareFuse 近炸诱骗成功自毁

* [x] 敌机被锁定/导弹来袭时执行规避机动并释放干扰弹，存在规避成功的可能
  * 验证：敌机 evade 模式（随机方向满杆滚转+拉杆 3 秒）+ 自动释放干扰弹（实测第一局敌机被锁定时进入规避机动）；导弹来袭触发同一规避路径

* [x] 敌机会主动追击玩家并进入包线后开火（机炮/导弹），构成实际威胁
  * 验证：实测三局玩家均被击落、僚机两局全灭（2/2→0/2）；敌机完美咬尾追击（雷达持续显示敌机在玩家六点钟）；导弹告警持续 60 秒（多枚导弹连续追踪）；机炮前置量瞄准 + 导弹包线（600-3000m/15°锥）开火

## 任务与结算

* [x] 存在 1 个完整战役任务，流程为：简报 → 入场 → 目标推进 → 胜利/失败结算
  * 验证：实测全流程——机库选机 → 打字机简报（6 段叙事+三阶段目标）→ 开始任务 → 阶段目标推进（击坠 1/4→2/4 HUD 实时更新）→ 失败结算；三阶段编排（制空→防空阵地→拦截+护卫）

* [x] 胜利条件（必需目标全部完成）正确触发胜利结算
  * 验证：代码审查——snapshot.objectives.every(done) → 阶段推进/最终 victory；评分（击坠+剩余资源+时间）与评价等级阈值匹配完整

* [x] 三种失败条件（玩家坠毁/任务超时/保护目标全部损毁）均正确触发失败结算
  * 验证：实测玩家坠毁路径（两局"失败原因：座机被击落"）；超时（timeRemaining≤0 与阶段时限双路径）与护卫全灭（allyIds 存活扫描）代码完整；结算界面三种失败原因文案映射齐全

* [x] 结算界面展示得分、评价等级、击坠数、用时，支持重开任务
  * 验证：实测两局结算（总得分 150/300、评价 D、击坠敌机 1/2、击坠轰炸机 0、摧毁地面目标 0、任务用时 4分15秒/2分24秒）；重开按钮实测可用（页面刷新回机库重新选机）

## 代码质量

* [x] 代码遵循 simulation（规则/AI/任务状态）/ render（Three.js 适配）/ ui（DOM HUD）目录边界，游戏状态不驻留 Three.js 对象

* [x] 所有函数附函数级注释（功能、参数、返回值、异常、注意事项）
  * 验证：逐文件审查 simulation/render/ui/core/config 全部导出函数、类方法、工厂函数——均含完整 JSDoc（功能描述、@param/@returns、异常说明、注意事项）

* [x] 战机/武器/任务均由配置表数据驱动
